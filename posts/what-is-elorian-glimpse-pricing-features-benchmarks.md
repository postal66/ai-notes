# What Is Elorian Glimpse? Pricing, Features & Benchmarks

![What Is Elorian Glimpse? Pricing, Features & Benchmarks](https://resource.cometapi.com/console/blog-banner/2026/10/622ee8e11b2045b39787f71453ea1aec.jpg)

## TL;DR

Elorian Glimpse is a multimodal visual reasoning model announced on October 16, 2026. It can revisit images, inspect video frames, and refine visual evidence during reasoning. Its announced API pricing is $0.60 per million input tokens and $3.00 per million output tokens. Elorian reports competitive performance in object counting, robotics events, charts, and video captioning, although these vendor-reported results are not comprehensive independent validation.

## Key Takeaways

- Visual thinking allows renewed inspection of image and video evidence rather than only an initial visual pass.
- Glimpse is reported to score 42.70 on WGO Bench, 92.90 on CharXiv-R, and 83.36 on FSC-147.
- Published API rates are $0.60 input and $3.00 output per million tokens.
- The model accepts text, image, and video inputs and generates text output.
- Developers should compare accuracy, latency, and total task costs before adopting it.
