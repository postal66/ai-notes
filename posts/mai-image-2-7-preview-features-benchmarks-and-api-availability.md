# MAI Image 2.7 Preview: Features, Benchmarks, and API Availability

![MAI Image 2.7 Preview: Features, Benchmarks, and API Availability](https://resource.cometapi.com/console/blog-banner/2026/11/f70b7c91cc0b44a5976da1083df5e206.png)

## TL;DR

[MAI-Image-2.7-Preview](https://microsoft.ai/news/mai-image-2-7-debut/) is Microsoft's AI image-editing model, introduced on October 27, 2026. It focuses on controlled changes to existing images, including lighting, visual style, objects, and typography.

Microsoft announced MAI Image 2.7 at No. 3 on Arena Edit and No. 2 on Artificial Analysis. In the October 28, 2026 snapshot reviewed for this article, it scored 1,193 Elo on Artificial Analysis and ranked second. For designers, its value lies in making substantial edits while preserving elements that already work.

Developers can evaluate the model through public testing platforms, but Microsoft has not announced a public 2.7 API or pricing as of October 28, 2026.

## Key Takeaways

- **Released October 27, 2026:** Microsoft introduced MAI-Image-2.7-Preview as an image-editing-focused successor to MAI-Image-2.6.
