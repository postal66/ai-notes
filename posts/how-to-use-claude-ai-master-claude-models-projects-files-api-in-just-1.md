## Demonstration of Core Features (Conversations, Files, Projects)

A smart first-hour workflow looks like this: start in a normal chat, ask one well-scoped task, upload one file, create one Project for a recurring use case, then move one repeated prompt into that Project. That sequence teaches you Claude’s interface without overwhelming you. It also mirrors Anthropic’s own guidance to combine related tasks, provide upfront background, and reuse context instead of repeating it.

### 1. Conversations & Smart Prompting

Every chat starts simple. Type your request and hit Enter. **Pro features in 2026**:

- **Memory**: Claude remembers across chats in the same Project.
- **Extended/Adaptive Thinking**: Toggle for deeper reasoning (Opus/Sonnet).
- **Web Search**: Built-in for up-to-date info.

**Example beginner prompt**: “Explain Claude Opus 4.7 vs Sonnet 4.6 like I’m 5, then give a technical comparison table.”

### 2. Uploading and Analyzing Files

Click the **+** icon in the chat box → Upload PDFs, CSVs, images, code files (up to 30MB per file in Projects).

**Real use case**: Upload a 200-page PDF contract → “Summarize risks and suggest redlines.” Claude extracts text instantly and reasons across the entire document thanks to 1M context.

Supported formats (2026): PDF (multimodal), DOCX, TXT, CSV, images up to 8000x8000px, code files.

### 3. Projects – Your Personal Knowledge Base (The Game-Changer)

Projects turn Claude into a persistent workspace.

**Step-by-step to create your first Project (60 seconds):**

1. Left sidebar → **Projects** → **+ New Project**.
2. Name it (e.g., “Q2 Marketing Campaign”).
3. Add **Description** + **Custom Instructions** (e.g., “Always respond in British English, tone = professional yet friendly”).
4. **Knowledge** tab → Upload files (brand guidelines, past campaigns, data sheets). These stay forever.
5. Start chatting inside the Project—Claude references *everything* automatically.

**Advanced Projects tips**:

- Create one per client/project to avoid context bleed.
- Use **Artifacts** for live previews (code → rendered UI).
- Share Projects with Team plan.

Real user data: Power users report 3–5x productivity because they never re-explain context.

One of the most practical benefits is caching. Anthropic says content in Projects is cached and does not count against limits when reused, and similar prompts are partially cached too. That means a well-built Project can save both time and usage while also keeping the assistant’s responses more consistent across multiple chats.

## Advanced Usage Tips: Prompt Writing & API Access

### Prompt Engineering Mastery (2026 Edition)

Claude follows instructions *extremely* well. Use this framework:

1. **Role**: “You are a world-class senior product manager…”
2. **Task + Constraints**: “Analyze this CSV. Output ONLY a markdown table with columns: Insight, Evidence, Recommendation. No fluff.”
3. **Examples** (few-shot): Give 1–2 input/output examples.
4. **Chain-of-Thought**: “Think step-by-step before answering.”
5. **Iterate**: Use “Improve this output by 30% on clarity and depth.”
6. When the task is current or time-sensitive, recommending explicitly asking it to use web search. Free users have daily usage limits and that web search and fetch both count toward those limits. In other words, use web search when freshness matters, but do not turn it on casually if you are trying to conserve capacity.

### API access: when you outgrow the chat window

That makes caching particularly useful for workflows such as support automation, document pipelines, and recurring content generation.
