# How to Use GPT-6.1 Terra API

![How to Use GPT-6.1 Terra API](https://resource.cometapi.com/console/blog-banner/2026/10/ee4a1bde4a224972a3c16175f7271f85.jpg)

## TLDR

GPT-6.1 Terra (gpt-6.1-terra) is OpenAI’s mid-tier GPT-6.1 model released on October 26, 2026. It delivers strong visual reasoning, precise computer use, and natural writing at half the price of GPT-6.1 Sol and GPT-5.6 Terra ($1 input / $5 output per million tokens standard). With a 1.05M-token context window, configurable reasoning effort (none to max), image input, and full tool support via the Responses API, it is ideal for high-volume agentic workflows such as invoice processing, technical drawing interpretation, screen interaction, and document revision. This guide covers exact setup, code examples, reasoning strategies, best practices, comparisons, and how to access it more cost-effectively through CometAPI.

## Key Takeaways

- Model ID: `gpt-6.1-terra` — 1,050,000 context window, 128,000 max output tokens, knowledge cutoff June 1, 2026.
- Pricing (OpenAI standard): $1 / $5 per 1M input/output tokens; cached input $0.05; long-context (>272K input) and Fast mode cost more.
