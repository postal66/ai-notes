# How to Use GPT Image 2.6 API: SVG Generation and Image Editing

![How to Use GPT Image 2.6 API: SVG Generation and Image Editing](https://resource.cometapi.com/console/blog-banner/2026/11/f2b52c23ebb54ff1ae44b3b4f4a2bece.png)

## TL;DR

[GPT Image 2.6 API](https://www.cometapi.com/models/openai/gpt-image-2-6/) in CometAPI gives developers a practical route to image generation and editing with two variants: Sunburst and Flare.

Build image assets with Python and a CometAPI key: start with a raster request, then add SVG output, reference images, or a transparent PNG annotation layer when your route supports them. The examples use Python 3.10 or later and keep the API key on your server.

The distinction that matters most: **a transparent PNG output is a finished asset; a transparent PNG markup file is an input that tells the model where to edit.**

## Key Takeaways

- Use GPT Image 2.6 Flare for quick drafts and Sunburst for detailed revisions.
- Send generation requests and edit requests to their respective Image API endpoints.
