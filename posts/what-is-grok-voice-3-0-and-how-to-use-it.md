# What Is Grok Voice 3.0 and How to Use It?

![What Is Grok Voice 3.0 and How to Use It?](https://resource.cometapi.com/console/blog-banner/2026/11/5706d60bf0684774b022494f3c0ae1d4.png)

## TL;DR

[Grok Voice 3.0](https://x.ai/news/grok-voice-3) is xAI’s real-time speech-to-speech model, released on October 14, 2026. Its API model name is `grok-voice-3.0`; as of November 3, 2026, [`grok-voice-latest points to this version`](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech#model-selection). The [launch announcement](https://x.ai/news/grok-voice-3) lists voice sessions at $0.08 per minute ($4.80 per hour). It combines conversation, interruption handling, and tool use for voice assistants and customer support. With basic Python, an xAI API key, and the websockets library, you can send a prompt and save a spoken reply. Start with the example below, then add recorded audio, live microphone streaming, and business tools as your application grows.
