# GPT-6.1 Terra: Benchmarks, API Pricing & Access

![GPT-6.1 Terra: Benchmarks, API Pricing & Access](https://resource.cometapi.com/console/blog-banner/2026/10/f4fc199ad38d497f994e8d27059075e2.webp)

## TL;DR

GPT-6.1 Terra is OpenAI's efficiency-focused model, officially released on October 26, 2026. It combines detailed visual reasoning, computer use, and natural writing with a 1,050,000-token context window. Standard API rates are $1 per million input tokens and $5 per million output tokens, half the rates of GPT-6.1 Sol.

Its biggest improvement is agent efficiency. On Agents' Last Exam, OpenAI reports a 15-percentage-point gain over GPT-5.6 Terra at medium reasoning effort, at roughly one-third the cost per task. The model also reaches 50.3% on Terminal-Bench 4.0 at maximum effort, more than double its predecessor's score.

For developers, Terra provides a balance between the economical GPT-6 Luna and the more powerful GPT-6.1 Sol and GPT-6 Astra. GPT-6.1 Terra API in CometAPI is now available, with published rates of $0.80 per million input tokens and $4.00 per million output tokens as of October 27, 2026.
