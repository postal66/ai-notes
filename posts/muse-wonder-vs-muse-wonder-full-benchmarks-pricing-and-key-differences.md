# Muse Wonder vs Muse Wonder Full: Benchmarks, Pricing, and Key Differences

![Muse Wonder vs Muse Wonder Full: Benchmarks, Pricing, and Key Differences](https://resource.cometapi.com/111%E4%B8%8B%E8%BD%BD.png)

## TL;DR

Meta launched [Muse Wonder](https://about.fb.com/news/2026/10/introducing-muse-wonder-models/) and Muse Wonder Full on October 12, 2026. Wonder is available through Meta Model API and Muse Code, while Full is available in Muse Code through the Power Usage and Maximum Usage subscriptions. Full leads on several published benchmarks, but the practical choice depends on API access, task quality, and cost. This comparison reviews published sources and does not include independent hands-on testing.

## Key Takeaways

- Wonder supports API integration; Full is available through Muse Code Power Usage and Maximum Usage subscriptions.
- Meta’s launch chart reports Artificial Analysis Intelligence Index scores of 52 for Wonder and 56 for Full. The four-point gap does not represent a universal percentage improvement in task performance.
- Wonder supports a 1,048,576-token context window and text, image, audio, video, and PDF input, with text output.
