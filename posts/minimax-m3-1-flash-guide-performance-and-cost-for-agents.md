# MiniMax M3.1 Flash Guide: Performance and Cost for Agents

![MiniMax M3.1 Flash Guide: Performance and Cost for Agents](https://resource.cometapi.com/m31-flash-zh-1-1792403273121.webp)

## TL;DR

MiniMax M3.1 Flash is a high-speed AI model designed for autonomous agents, software engineering, computer use, and complex workflow automation. Officially released on October 19, 2026, it combines a 1-million-token context window with configurable reasoning depth and lower inference costs.

MiniMax reports up to 200+ output tokens per second, a 70% reduction in agent workload costs compared with its predecessor, and competitive performance across Automation-Bench, DeepSWE, and OSWorld. At $0.15 per million input tokens and $0.60 per million output tokens, the model makes multi-step AI agent workflows more economical.

## Key Takeaways

- MiniMax M3.1 Flash performance: Vendor-reported benchmarks include Automation-Bench 62.8, DeepSWE v1.1 73.7, and OSWorld 2.0 61.7, highlighting its capabilities in agent automation, coding, and computer use.
- MiniMax M3.1 Flash API pricing: Official rates are $0.15/M input, $0.60/M output, and $0.015/M cached input. CometAPI rates are $0.80/M input and $3.20/M output as of October 21, 2026, with no published cache rate on its model page.
